## 0. 产品定位

训练"信息不完全条件下的结构化决策能力"的决策仿真平台。
主线：**信息稀缺下的结构化决策闭环**。多 Agent / LLM 是实现手段，非本体。

## 1. 能力模型（评审三问的答案口径，必须落到产品与汇报中）

### 1.1 养成路径（闭环）

```
接收任务 → 发现信息源 → 访谈与验证 → 建立决策模型 → 提交决策 → 观察后果 → 证据化复盘
```

### 1.2 六分能力（可训练、可测量）

| 分能力 | 训练机制 | 可观测指标 |
|--------|---------|-----------|
| 信息源定位 | 4 角色各持不可替代事实，删除任一角色场景坍缩 | 关键干系人识别率 |
| 主动信息获取 | 三层信息分级 + 弱信号/面包屑/正式询问 | 红线事实获取率 |
| 信息甄别与交叉验证 | 4 组冲突事实 + 跨角色引用 | 冲突验证率 |
| 问题结构化 | 强制六要素决策工作台 | 方案可行率 |
| 取舍决策与风险预案 | 稀缺预算 + 硬约束 + 应急方案 | 预案完整度 |
| 证据化复盘与迁移 | 复盘报告 + 平行场景 | 平行场景迁移改善率 |

### 1.3 训练方法：脚手架递减

1. 第一遍系统给引导，学生填空；2. 第二遍撤引导，学生自己搭结构；3. 用"内容不同、结构相同"的平行场景验证迁移。
路线图：脚手架节奏做成个性化 → 强化学习教练策略（状态=学生能力画像，动作=脚手架/难度，奖励=平行场景迁移改善率）。

## 2. 信息不完全的实现（四维度，核心卖点）

| 维度 | 含义 | 状态 |
|------|------|------|
| 分散 | 每条红线事实恰好一个完整持有者，需拼装（2500 阈值 vs 3200 峰值） | ✅ 已落地 |
| 分层 | L0 公开 / L2 普通隐藏 / L3 高价值隐藏 + 三条正式询问通道 | ✅ 已落地 |
| 稀缺 | 获取信息消耗时间/次数预算，必须取舍 | ✅ v0.2 已落地：引擎消费 40min 预算，每次访谈按意图/角色/信息增量扣减 |
| 噪声 | 角色有立场/偏差/弱信号/安慰性假安心（如 staging 800 上限测不到 2500） | ✅ 已落地 |

**披露防剧透铁律**：披露决定在规则引擎，LLM 只负责措辞；真值表是唯一数据源。

## 3. 结构性决策的体现

### 3.1 访谈设计（已落地）
每个角色有不可替代事实、独立立场、披露条件、弱信号。访谈=拼图，不是聊天；支持跨角色"拿 A 的数据打 B 的脸"。

### 3.2 决策工作台（P0 已落地 v0.2）
学生被要求把对话外化为六要素：**事实 / 目标 / 硬约束 / 方案 / 风险 / 证据引用**。提交 D2 前必须填齐六要素；后端拒绝只提交方案字符串，并校验引用证据是否已获取、是否至少 3 条。
