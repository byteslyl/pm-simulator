模块间接口定义（9/5 冻结）

接口 产出方 消费方 数据格式 说明
意图分类结果 刘俊辰 Agent 路毅 关系引擎 { intent: "risk_inquiry", confidence: 0.92 } 五类：structured_query / risk_inquiry / plan_negotiation / resource_inquiry / strategic_alignment
信任档位 路毅 关系引擎 刘俊辰 Agent { role: "R2", level: "cooperative", score: 68 } 四档：resistant / neutral / cooperative / trusting
事实披露记录 刘俊辰 Agent 路毅 评分引擎 { factId: "F-04", source: "R2", method: "formal_inquiry" } method: keyword / formal_inquiry / trust_unlock / auto_disclose
约束检查结果 路毅 约束引擎 路毅 结果引擎 { constraint: "C-05", violated: true, detail: "..." } 内部消费，路毅自己闭环
状态变量 路毅 状态机 路毅 结果引擎 { S1: 75, S2: "high", S3: 60 } 内部消费，路毅自己闭环

路毅的 6 个引擎模块中有 4 个是内部消费（约束→状态→评分→结果→日志），只有关系引擎需要和 Agent 交互。线上开发独立性高。
